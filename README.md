ENG

This is a layered ASP.NET MVC 4.6.1 web application that allows users to upload, manage, and download files using Amazon S3 for storage and PostgreSQL for database management.

Key Features

Users can upload files which are stored in Amazon S3.
Uploaded file metadata is stored in a PostgreSQL table.
Users can download or delete their uploaded files.
All actions are logged and can be reviewed through a log screen.
Built using C#, HTML, CSS, JavaScript and structured in a layered architecture for maintainability and scalability.

Technologies Used

.NET Framework 4.6.1  /
ASP.NET MVC / 
C# / 
HTML / CSS / JavaScript / 
PostgreSQL / 
Amazon S3

How It Works

User uploads a file through the web interface.
The file is stored in Amazon S3, and metadata (filename, upload date, user info, etc.) is saved in PostgreSQL.
Users can view a list of uploaded files, download them, or delete them.
All user actions are logged and can be monitored through the log screen.
